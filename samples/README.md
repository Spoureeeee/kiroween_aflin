# Sample data

`statement-sample.csv` is **synthetic**. Every merchant, amount and date is fictional and generated by a script. It contains no real bank data and no real brand names.

Columns: `Date` (DD/MM/YYYY), `Description`, `Amount` (negative = money out, positive = money in).

It is built to exercise the detector:

| Case | Example |
|---|---|
| Clean monthly subscription | SPOTIFLY PREMIUM, CLOUDBOX 200GB STORAGE |
| Price increase mid-series | NIGHTFLIX.COM (55.90 then 59.90 from September) |
| Changing reference numbers in the description | NIGHTFLIX.COM 8823 / 9141 / ... |
| Forgotten gym-style membership | IRONHOUSE GYM MEMBERSHIP |
| Free trial that converted to paid | PIXELPRO TRIAL CONVERSION (from August) |
| Quarterly charge | READLY NEWS DIGITAL |
| Annual charge seen only once | DOMAINNEST ANNUAL RENEWAL |
| Legitimate recurring bill | MOBILEONE POSTPAID BILL |
| Positive amounts (salary, refund) | SALARY CREDIT, REFUND BOOKNOOK ONLINE |
| Same-day duplicate that is not recurring | QUICKBITE DELIVERY on 18/06/2026 |
| Random noise | groceries, fuel, food delivery, e-wallet reloads |
